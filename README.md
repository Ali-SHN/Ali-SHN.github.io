# Ali Sharifian — personal research portfolio

A dependency-free static portfolio prepared for GitHub Pages at `https://ali-shn.github.io/`.

## Publish

1. Create a public GitHub repository named `Ali-SHN.github.io`.
2. Push this folder to the repository's `main` branch.
3. In **Settings → Pages**, choose **Deploy from a branch**, then `main` and `/ (root)`.

The site will normally appear at `https://ali-shn.github.io/` after GitHub finishes the first deployment.

## Important profile-link note

LinkedIn and GitHub point to Ali's public profiles. The Scholar buttons currently use a precise Google Scholar author search because a public Scholar profile ID could not be verified. If you have the direct profile URL, replace every `https://scholar.google.com/scholar?...` link in `index.html` with it.

## Local preview

The site has no build step. Open `index.html` directly in a browser, or serve this folder with any local static server.

## Structure

- `index.html` — content and page structure
- `styles.css` — responsive layout, themes, and motion
- `script.js` — theme switcher, mobile menu, reveal effects, and molecular particle field
- `assets/` — portrait and research visuals

All project visuals are sourced from Ali's local research repositories.
